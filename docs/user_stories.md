# User Stories
## Marketing Performance Intelligence Agent

## Epic 1: Marketing Data Foundation

**US-01: Unified marketing data**

As a marketing analyst, I want marketing performance data from multiple sources represented in a consistent warehouse so that I can analyze performance across platforms.

**US-02: Data quality validation**

As a marketing analyst, I want the system to identify missing, duplicated or inconsistent data so that I can trust the analysis.

**US-03: Consistent metric definitions**

As a marketing manager, I want all KPIs to have centrally defined business logic so that different investigations use consistent calculations.

## Epic 2: Natural-Language Marketing Analysis

**US-04: Submit a business question**

As a marketing manager, I want to ask marketing questions in natural language so that I do not need to write SQL.

**US-05: Clarify ambiguous requests**

As a marketing manager, I want the agent to ask for missing essential information so that it does not analyze the wrong date range, platform or KPI.

**US-06: Resolve metric definitions**

As a marketing analyst, I want the agent to use approved metric definitions so that the calculations follow business rules.

## Epic 3: Performance Investigation

**US-07: Compare marketing performance**

As a marketing manager, I want to compare current and previous performance periods so that I can identify changes in KPIs.

**US-08: Identify campaign drivers**

As a marketing manager, I want to identify which campaigns contributed to KPI changes so that I can prioritize optimization.

**US-09: Investigate the conversion funnel**

As a growth manager, I want to identify where users drop off in the conversion funnel so that I can investigate performance bottlenecks.

**US-10: View supporting evidence**

As a marketing manager, I want to inspect the data behind the agent's conclusions so that I can evaluate whether its findings are reliable.

## Epic 4: Marketing Recommendations

**US-11: Receive optimization recommendations**

As a marketing manager, I want the agent to recommend optimization opportunities based on performance evidence so that I can make informed decisions.

**US-12: Review budget allocation proposals**

As a marketing manager, I want to see proposed budget allocations alongside the current allocation so that I can evaluate changes before approving them.

## Epic 5: Human Approval and Execution

**US-13: Approve a recommendation**

As an authorized marketing manager, I want to approve a proposed action so that the application can execute it.

**US-14: Edit a recommendation**

As an authorized marketing manager, I want to edit proposed action parameters so that the final action reflects my business judgment.

**US-15: Reject a recommendation**

As a marketing manager, I want to reject a recommendation so that no unwanted action is executed.

**US-16: View execution status**

As a marketing manager, I want to see whether an approved action succeeded or failed so that I can track the outcome.

## Epic 6: Governance and Evaluation

**US-17: View investigation history**

As a marketing manager, I want to review previous investigations so that I can understand past decisions and recommendations.

**US-18: Track action approvals**

As an administrator, I want approval and execution records so that I can audit protected actions.

**US-19: Evaluate agent quality**

As a product owner, I want benchmark tests for common marketing questions so that I can measure agent reliability.

**US-20: Understand limitations**

As a marketing manager, I want the agent to disclose missing data and uncertain conclusions so that I do not mistake assumptions for facts.
